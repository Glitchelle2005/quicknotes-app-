# QuickNotes App

QuickNotes is a simple note‑taking web app built with HTML, CSS, and JavaScript. It lets you add, delete, search, and categorize notes, with data saved in localStorage so your notes remain after refresh.

## Features
- Add notes with categories (Personal, Work, Study)
- Delete notes individually
- Search notes by text
- Validation for empty or too‑long notes
- Responsive design with Flexbox and media queries
- Notes persist across refreshes using localStorage
